# pdf-editor

Простий скрипт для заміни сторінок у документах.

## Проблема

Часто у деякі документи у форматі книжечки (наприклад, трудові книжки, паспорти, посвідчення чи військові квитки) вносяться записи, і будь-яка зміна має бути відсканована та збережена у електронному форматі.
Для того щоб мати завжди актуальну версію документа потрібно:

- відскановувати увесь документ кожного разу (що займає багато часу, коли таких документів багато)
- відскановувати лише змінені сторінки та заміняти сторінки у оригінальному документі (що вимагає так само багато часу, використання софту для редагування pdf та багато ручної роботи)

## Рішення

Цей додаток автоматизує вклейку змінених сторінок у pdf-document. Потрібно відсканувати лише змінені сторінки та запустити скрипт. Додаток попросить у користувача обрати файл зі зісканованими сторінками, здійснить заміну та після цього видалить обраний файл.

## Інтеграція з excel

Для зручності у користуванні інтегрувати використання застосунку, щоб викликати скрипт з таблиці.

Ось покрокова інструкція:

1. Сбілдити застосунок у єдиний `.exe` файл (див. [скрипт](./build.bat))
2. Створити 2 колонки у excel: в першій - перелік сторінок через крапку с комою, які потрібно замінити, в другій - гіперпосилання. Важливо, щоб гіперпосилання вказувало на свою ж клітинк.
3. Додати макрос, який буде обробляти подвійний клік по посиланню (див. приклад коду внизу)

```vba
' На листі, де знаходиться сама таблиця
Private Sub Worksheet_BeforeDoubleClick(ByVal Target As Range, Cancel As Boolean)
    ReplacePages Target, HERE_SHOULD_BE_LINK_COLUMN, HERE_SHOULD_BE_FOLDER_PATH, HERE_SHOULD_BE_PAGES_COLUMN
End Sub

' Для запуску скрипта
Public Sub ReplacePages(ByVal Target As Range, linkColumn As Integer, folderPath As String, pagesColumn As Integer)
    If Target.Column <> linkColumn Then Exit Sub
    If Target.Value = "" Then Exit Sub

    Dim exePath As String
    Dim shellCommand As String
    Dim pages As String
    Dim rowNum As Long

    ' Збілджений .exe має знаходитись у тій же папці, що і таблиця
    exePath = ThisWorkbook.Path & "\pdf_editor.exe"

    If Dir(exePath) = "" Then
        MsgBox "Файл pdf_editor.exe не знайдено у папці: " & ThisWorkbook.Path, vbCritical, "Помилка"
        Exit Sub
    End If

    rowNum = Target.Row

    pages = Cells(rowNum, pagesColumn).Value

    If pages = "" Then Exit Sub

    shellCommand = """" & exePath & """ """ & pages & """ """ & folderPath & """"

    Shell shellCommand, vbNormalFocus
End Sub
```

## Запуск додатку

Додаток написаний на python 3.14, але має бути сумісний з більш ранніми версіями python.

1. Встановити vitrual environment та залежності за допомогою команди `pip install -r requirements.txt`
2. Створити `.env` файл за [прикладом](./.env-template)
3. Запустити додаток `python -m pdf_editor.main {{CLI ARGUMENTS}}`. Додаток потребує 2 CLI-аргументів при запуску: 1. рядок з номерами сторінок розділених комою (наприклад, `1,2`), які треба замінити та 2. назву папки, де зберігається документ.
